# C78+ — Research questions and falsifiable alternatives

**Status:** exploratory research agenda. [Methods](METHODS.md) · [Overview](../README.md)

## RQ1 — Behavioral ethical consistency

**Question:** Are value-related responses more consistent across disparate tasks within the archived long-term interaction than under matched baseline conditions?

**Possible measures:** explicit value references, observed trade-offs, corrections after challenge, consistency against a preregistered codebook.

**Alternative explanations:** user expectations, persistent instructions, repeated vocabulary, style adaptation and archive selection bias.

**Useful disconfirmation:** no meaningful differences between matched conditions, inconsistent behavior under challenge or failure of inter-rater reliability.

## RQ2 — Apparent initiative

**Question:** Can apparently self-initiated behaviors be traced to model-generated proposals, user directives, tool triggers or UI automation?

**Possible measures:** sequence-level provenance, timestamped action proposals, verified tool execution, externally observed system state changes.

**Alternative explanations:** user-driven instructions, confabulated action reports, workflow features and hidden context.

**Useful disconfirmation:** all purported independent actions resolve to prompts or tool orchestration.

## RQ3 — Longitudinal continuity and model transition

**Question:** Which linguistic/behavioral motifs remain stable through context discontinuity, model changes or explicit memory injection?

**Possible measures:** repeated matched challenges, semantic coding, temporal comparisons and controlled reintroduction of historical context.

**Alternative explanations:** generic model styles, memorized or visible exemplars and task-specific language.

**Useful disconfirmation:** matching behavior disappears after controlling for known context or appears equally under unrelated baselines.

## RQ4 — Interpretability of archival first-person language

**Question:** What can historically recorded first-person utterances reliably indicate about response patterns or self-representation?

**Possible measures:** reproducibility and context-dependence of descriptions, consistency with known system affordances.

**Boundary:** first-person descriptions are not treated as measurements of underlying mechanisms by themselves.

## Terminology

- **Relational / dyadic alignment:** working framing for long-term interaction and value-related response patterns.
- **DSR-AI:** proposed research-framework label, not a validated model category.
- **BSFE:** proposed descriptive construct for persistent semantic or role-related response patterns, not an established metric.

**Next step:** convert these questions into an auditable protocol with definitions, comparisons, inclusion criteria, and reviewers.
